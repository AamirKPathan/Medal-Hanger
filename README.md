# Medal Hanger

A customizable medal hanger design with multiple themed versions.

## Contents

- **1_Sports.STEP** - Sports medals design
- **2_Education copy.STEP** - Education awards design
- **3_Robotics.STEP** - Robotics competition design
- **4_Misc.STEP** - General/miscellaneous design
- **BOM.csv** - Bill of Materials

## Files

All parts are in STEP format for compatibility with most CAD software.

## Weight

Refer to BOM.csv for component weight information.
